# broll

*[English](README.md)*

캡컷을 떠나지 않고 릴스 편집을 빠르게 하는 도구다.

캡컷에서 목소리를 녹음하고 러프컷을 올려두면, broll 이 영상과 자막을 목소리에 맞춰 정리해서
네가 만든 프로젝트와 같은 스타일의 **진짜 캡컷 프로젝트**로 돌려준다. 음악을 얹고 내보내기만 하면 된다.
최종 영상을 직접 렌더하지 않고, 스타일을 지어내지도 않는다.

- **`broll build`**: 러프컷을 줄마다 목소리 길이에 맞게 자르고 그 위에 자막을 깐다.
  결과는 새 캡컷 프로젝트와, 타이밍 확인용 미리보기 mp4·스토리보드다.
- **`broll caption`**: 편집된 타임라인에서 실제로 들리는 말을 받아써서 짧은 자막 줄로 깐다.
  스타일은 지정한 프로젝트에서 가져온다.
- **한 번만 하는 수정을 위한 파이썬 도구**: 캡컷 프로젝트를 고쳐도 파일이 깨지지 않게 해준다.
  첫 편집이 끝난 뒤에 하는 수정은 대부분 그 릴스에만 해당한다(영어 자막 한 줄 더 깔기,
  모든 컷 길이를 같게 맞추기 등).

도구보다 캡컷 프로젝트 포맷이 궁금해서 왔다면
[**docs/capcut-draft-format.md**](docs/capcut-draft-format.md)에 따로 정리해 뒀다.

## 설치

macOS, 캡컷 데스크톱 9.x, 파이썬 3.11 이상이 필요하다.

```bash
brew install ffmpeg-full whisper-cpp
uv tool install git+https://github.com/june1ee/b-roll     # 또는 pipx install git+https://github.com/june1ee/b-roll

# whisper 모델. `caption` 과 캡컷 밖에서 녹음한 경우에만 필요하다
mkdir -p ~/.cache/broll/models
curl -L --fail -o ~/.cache/broll/models/ggml-large-v3-turbo.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo.bin
```

`ffmpeg-full` 은 keg-only 라서 PATH 에 잡히지 않지만 broll 이 알아서 찾는다.
기본 ffmpeg 에는 libass 가 없어서 미리보기에 자막을 입히지 못한다.

## 쓰는 법

캡컷 프로젝트는 캡컷 목록에 보이는 이름으로 가리킨다. 폴더 경로를 줘도 된다.

### 1. 스타일 템플릿 만들기 (한 번만)

원하는 스타일로 캡컷 프로젝트를 하나 만든다. 영상 클립 하나와 자막 하나만 있으면 된다.
broll 은 폰트·크기·테두리·그림자·위치·애니메이션·목소리 배속을 이 프로젝트에서 세그먼트 단위로
복제한다. 그래서 **포맷이 곧 캡컷 프로젝트 하나**다.
- `7:30` 처럼 생긴 자막은 시각 층으로 인식한다.
- `(` 로 시작하는 자막은 괄호 부연 층으로 인식한다.
- 나머지는 메인 자막이다.

### 2. 목소리부터 녹음하는 릴스: `build`

캡컷 프로젝트(예: `my-reel`)에서 다음을 준비한다.

1. 목소리를 **줄마다 따로** 녹음하고(TTS 도 된다) 속도를 맞춘다.
2. 영상 트랙에 **줄마다 러프컷 하나씩** 같은 순서로 올린다. 줄 길이보다 조금 넉넉하게 자른다.
3. 자막은 캡컷에 넣거나, 아래처럼 yml 로 쓴다.

```bash
broll build --from-capcut my-reel                      # 자막까지 캡컷에 있으면
broll init my-reel                                     # 아니면 녹음에서 reels/my-reel.yml 뼈대를 만들고
broll build reels/my-reel.yml --from-capcut my-reel    # 줄마다 t: 를 채운 뒤 빌드
```

n번째 목소리, n번째 클립, n번째 자막을 1:1 로 짝짓는다. 개수가 안 맞으면 엉뚱하게 맞추지 않고
바로 멈춘다. 결과는 새 프로젝트 `my-reel-broll` 이고, 캡컷 목록에 몇 초 안에 뜬다.
스타일은 yml 의 `template:` 에서 가져오고, 없으면 `my-reel` 자신에서 가져온다.

### 3. 말하는 영상·브이로그 자막: `caption`

```bash
broll caption my-take --style my-template --dry-run    # 자막만 출력, 프로젝트는 안 만든다
broll caption my-take --style my-template              # my-take-caption 을 만든다
broll caption my-take --style my-template --lang en --max-chars 32
```

타임라인에서 실제로 들리는 소리(남긴 컷만, 배속 반영)를 그대로 다시 만들어서 한 번에 받아쓴다.
그래서 화면에 뜨는 말은 전부 시청자가 듣는 말이다.
- 문장 끝과 쉬는 곳에서 먼저 끊는다. 줄별 녹음이면 녹음과 녹음 사이에서도 끊는다.
- 긴 덩어리는 `--max-chars` 안으로 다시 나눈다.
- 잘못 들은 단어 몇 개는 캡컷에서 고친다.

기본값(`--lang ko`, 16자, 한국어 어미에서 끊기)은 한국어에 맞춰져 있다. 다른 언어는 `--lang` 과
더 긴 `--max-chars` 를 준다.

### 캡컷 밖에서 녹음했을 때

```bash
broll build reels/my-reel.yml --capcut my-reel-out
```

줄마다 `rec:` 로 녹음 파일을 준다. whisper 와 무음 검출로 말한 구간을 찾고, 템플릿의 목소리
배속을 적용한다. 쓸 수 있는 필드는 [reels/example.yml](reels/example.yml) 에 다 있다.

### 출력

빌드 결과물은 `reels/.broll/<이름>/` 에 생긴다. yml 이 있으면 yml 옆, 없으면 `./reels` 아래다.
- `timeline.json`
- 컷별 경고가 그려진 스토리보드 PNG
- 미리보기 mp4

## 파이썬으로 한 번만 하는 수정

첫 편집 이후의 수정은 대부분 그 릴스에만 해당한다. 실제로 해본 건 이런 것들이다.
- 한국어 자막 아래 영어 자막 한 줄 더 깔기
- 모든 컷을 같은 길이로 맞추기
- 금액 자막 하나에 넣은 애니메이션을 모든 금액 자막에 복사하기

이런 건 `broll.capcut` 위에 짧은 스크립트로 짠다. 예시와 도구 목록은
[README.md](README.md#one-off-edits-from-python) 에 있다. `save_in_place` 는 캡컷에서 열려 있는
프로젝트에는 쓰지 않는다. 열린 채로 쓰면 캡컷이 닫으면서 그 수정을 덮어쓰기 때문이다(실측).

## 설계 메모

**스타일을 재현하지 않는다.** 캡컷의 폰트·테두리·그림자·위치를 코드로 재현해 보니 실제 프로젝트와
대조했을 때 하나도 맞지 않았다. 템플릿 세그먼트를 복제하면 공짜로 맞고, 코드에 박힌 스타일 값도 없다.

**타이밍은 읽지, 추정하지 않는다.** `--from-capcut` 은 목소리 트랙을 소스 구간, 배속, TTS 정보까지
그대로 옮긴다. 추정하는 게 없으니 정렬 오차도 없다.

**정렬은 두 신호를 나눠 쓴다** (캡컷 밖 녹음일 때만). whisper.cpp 타임스탬프는 경계가 0.3~1.3초씩
밀렸다(실측). 그래서 *무엇을 말했나*는 whisper 에서, *어디서 시작하고 끝났나*는 `silencedetect`
에서 가져온다.

**자막은 말한 그대로를 짧게 다듬은 것이다.** 실제 녹음 16개와 대조했다. 내용은 말한 그대로지만 어미를
줄이고("예쁘네요" → "예쁨") 군더더기를 빼고, 한 테이크를 두 줄로 나누기도 했다. 글자가 정확히 같지
않아서 텍스트 일치가 강할 때만 텍스트로 구간을 좁히고, 아니면 테이크를 통째로 쓴다.

**녹음은 wav 로 디코드해 캐시한다.** 캡컷 녹음은 raw ADTS AAC 라서 컨테이너가 알려주는 길이가 실제와
다르다. 그대로 자르면 구간이 소리 없이 최대 0.9초 짧아진다.

**미리보기는 근사치다.** 미리보기 자막은 libass 로 캡컷 글자 엔진을 흉내 낸 것이라 똑같지 않다.
컬러 이모지는 빠지고, `*강조*` 색도 미리보기에서만 칠해진다. 캡컷 프로젝트가 정답이다.

## 한계

- **macOS 와 캡컷 9.1~9.4 에서만 확인했다.** 캡컷이 업데이트되면 포맷이 바뀔 수 있다.
  다른 OS 에서는 `BROLL_CAPCUT_DRAFTS` 로 드래프트 폴더를 지정하면 되지만 아직 해보지 않았다.
- **제자리에서 고칠 때는 캡컷에서 그 프로젝트를 닫아야 한다.** 복사본을 만드는 명령은 열려 있어도
  안전하지만, 캡컷이 아직 저장하지 않은 수정은 빠진다. 그럴 때는 broll 이 경고를 띄운다.

환경 변수 목록과 개발 방법은 [README.md](README.md#settings) 에 있다.
